EcoRed Circular - demostración web estática

Archivos: index.html, styles.css, app.js.
Subir los tres archivos juntos a la carpeta raíz del servidor web.
Abrir http://IP_PUBLICA/ (si el servidor escucha en el puerto 80).

Inicio de sesión simulado: acepta cualquier correo y contraseña; el botón Google NO contacta Google.
Empresas y materiales se guardan en localStorage del navegador, no en el servidor.
Los datos no se comparten entre dispositivos, usuarios o navegadores y pueden borrarse al limpiar los datos del sitio.
No utilizar esta demostración para credenciales reales ni datos sensibles.
