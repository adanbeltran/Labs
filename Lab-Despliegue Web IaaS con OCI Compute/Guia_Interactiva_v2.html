1. De lo Físico a lo Virtual: Comprendiendo el Flujo de Red

Antes de configurar OCI, es vital entender que la nube es Redes Definidas por Software (SDN). Los dispositivos de hardware tradicionales que usábamos en los centros de datos ahora se representan como funciones lógicas.

Arquitectura Física (On-Premises)

En el mundo tradicional, la conectividad bidireccional a internet requiere hardware:

  • Enrutador/Firewall: Dispositivo perimetral que recibe la conexión del ISP, traduce direcciones (NAT) y aplica reglas físicas de seguridad.
  • Switches Físicos: Equipos que agrupan y segmentan el tráfico local (VLANs).
  • Servidor de Hardware: Una máquina con una Tarjeta de Red Física (NIC) conectada por cable al switch.
Esquema físico: Servidores, cableado, switches y routers de hardware.

Arquitectura Virtual (Oracle Cloud - OCI)

En la nube, el hardware desaparece de tu vista. Al crear recursos en el Taller 1, estás definiendo esta topología lógica:

  • Internet Gateway (IGW): Reemplaza al enrutador de borde. Gestiona la conexión bidireccional y el NAT.
  • VCN y Subredes: Reemplazan los switches físicos. La VCN es la red global, las Subredes segmentan el dominio de difusión.
  • Route Table & Security List: Reemplazan al Firewall. Se aplican a nivel de subred.
  • VNIC: La tarjeta de red virtual. Es el único punto por donde la Máquina Virtual (VM) puede hablar con la VCN.
Esquema virtual: VCN, Internet Gateway, Subredes, VNIC y Security Lists.

2. Redes explicadas como una ciudad

Para fijar los conceptos de OCI (Paso 2.1 a 2.4), usemos la analogía de una ciudad:

🏙️

VCN = ciudad privada

Una ciudad delimitada (ej. red-infraestructura).

10.0.0.0/16
🏘️

Subred = barrio

Una zona que agrupa máquinas con las mismas reglas (ej. subred-web).

10.0.0.0/24
🔌

VNIC = el contador/enchufe

La tarjeta que une la casa (VM) a la red del barrio (Subred).

IP Privada / IP Pública
🗺️

Route table = señales de tránsito

Indica por dónde enviar el tráfico que sale de la VCN.

0.0.0.0/0 → IGW
🌉

Internet Gateway = aduana de la ciudad

Permite salir/entrar de la ciudad pública (Internet).

salida-internet
🛂

Security List = control de acceso

Verifica en el barrio qué tipo de tráfico es autorizado.

Ingress: 80/22 | Egress: All

4. Direcciones IP, CIDR y puertos

¿Cuántas direcciones representa un CIDR?

Piensa en una avenida: el prefijo indica qué parte identifica el barrio; los bits restantes permiten identificar direcciones dentro de él.

En OCI, la subred reserva tres IP: dirección de red, primer host para el gateway virtual de la subred y última dirección de broadcast. Estas IPs no se pueden asignar a una VNIC.

Una IP puede tener muchas puertas

🚪
:22

SSH

🚪
:80

HTTP

🔒
:443

HTTPS

Ejemplo: 137.131.182.113:80 identifica la IP pública asignada a la VNIC y el servicio web HTTP esperando conexiones.

El CIDR 0.0.0.0/0 abarca todas las direcciones IPv4 de Internet. En una regla ingress indica cualquier origen externo; en una ruta por defecto (0.0.0.0/0 -> IGW) indica cómo enviar tráfico no local.
